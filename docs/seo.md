## Site owner checklist (free)
1. Verify https://www.ubeziste.com/ or the ubeziste.com domain in Google Search Console (DNS or provided verification method). Submit https://www.ubeziste.com/sitemap.xml.
2. In Bing Webmaster Tools, import verified Search Console site or verify separately, submit sitemap. Ecosia uses upstream providers; organic results do not require advertising.
3. Inspect and request indexing for home, rescue guide and species hub; monitor impressions, clicks, queries and indexing errors. Avoid repeated submissions or paid link schemes.
4. Publish original case reports, species-specific expert-reviewed articles and real photos with descriptive alt text. Obtain natural relevant links from partners with permission. Add meaningful pages to sitemap and link them from guide/hub.
5. Run PageSpeed Insights for home and rescue guide. Existing background PNG compression is still pending; follow tools/optimize_background.py and verify appearance before deploying optimized images.

## Technical checks
Unique H1s and canonical URLs, connected language alternates, static text, sitemap, shared asset versioning. No meta keywords/hidden text/doorway pages. No guaranteed indexing or rankings. Search Console and Bing ownership verification not performed here.
